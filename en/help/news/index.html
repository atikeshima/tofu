Help

What’s new

Changes in each version, newest first.

1.6.0 (October 28, 2026)

  • Import songs from MusicXML files exported by iReal Pro and other apps, including straight from iReal Pro's share screen → Import a song from iReal Pro or another app (MusicXML)
  • Send a song to iReal Pro → Send a song to iReal Pro
  • Rename the file when sharing a PDF → Print or send a PDF
  • The two-bar repeat sign (%%) now sits between the two measures with a "2" above it. The two measures move together when you select, delete or copy them → Add segno, coda, D.S. or a measure repeat (%)
  • When a section change falls where a new row starts, a double bar line (‖) now appears at both the end of the row before and the start of the new row. Fixed a double bar line you entered at the start of a row sometimes not showing → Name sections or change their order / Make the rows match the printed music
  • When the chord font is set to "Handwritten", signs such as segno, coda and D.S., and time signatures, are handwritten too → Use a handwritten chord font
  • Sort a setlist by name, date created or date modified, and switch back to your own order at any time → Sort a setlist by name, date and more
  • When you add songs to a setlist, the sort order you choose is used again the next time. It doesn't change the order of your song list → Make a setlist
  • The small metronome window always shows the current tempo. Tap the number to type a new one → Use the metronome
  • In time signatures like 12/8, where the top and bottom numbers have different numbers of digits, the bottom number is now centered instead of sitting to the left
  • Fixed files shared to Tofu from other apps sometimes not being imported when Tofu wasn't running → Send a song to someone, or receive one
  • Fixed the measure you tapped sometimes being hidden behind the chord entry panel that opens on the right in landscape → Enter a single chord

1.5.0 (October 23, 2026)

  • Dark Display: play in a dark room with a dark page and light text → Show the performance menu or change what's shown
  • Chords can use a "Handwritten" font → Use a handwritten chord font
  • "Fit to Margins" removes the top and bottom margins so the chart fills the screen → Zoom in on the chart
  • Song search treats hiragana and katakana, and full-width and half-width characters, as the same → Find or sort songs
  • An unchanged PDF score is shared as the original PDF → Rename or share a PDF score
  • When the microphone or camera can't be used, "Open Settings" takes you to allow it → Tune with the tuner / Scan paper music with the camera
  • In a narrow window, the metronome and tuner stay in the performance menu → Show the performance menu or change what's shown
  • The stopped metronome's small window can be closed with "×" → Use the metronome
  • Chords that don't fit in a measure are drawn smaller instead of being cut off → Enter a single chord
  • When only the bass note changes, only the slash and the bass note are written, like "C" then "/B" → Enter a single chord
