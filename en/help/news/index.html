What’s new

Changes in each version, newest first.

1.5.0 (October 23, 2026)

  • Dark Display: play in a dark room with a dark page and light text → Show the performance menu or change what's shown
  • Chords can use a "Handwritten" font → Use a handwritten chord font from 1.5.0
  • "Fit to Margins" removes the top and bottom margins so the chart fills the screen → Zoom in on the chart
  • Song search treats hiragana and katakana, and full-width and half-width characters, as the same → Find or sort songs
  • An unchanged PDF score is shared as the original PDF → Rename or share a PDF score
  • When the microphone or camera can't be used, "Open Settings" takes you to allow it → Tune with the tuner / Scan paper music with the camera
  • In a narrow window, the metronome and tuner stay in the performance menu → Show the performance menu or change what's shown
  • The stopped metronome's small window can be closed with "×" → Use the metronome
  • Chords that don't fit in a measure are drawn smaller instead of being cut off → Enter a single chord
  • When only the bass note changes, only the slash and the bass note are written, like "C" then "/B" → Enter a single chord
