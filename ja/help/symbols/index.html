使い方

記号と小節の形を整えたい

小節の足し方（最後・途中・先頭）、繰り返しと1番・2番カッコの付け方、セーニョ・コーダ・D.S.・to Coda・「%」の付け方、セクション名の付け方と並べ替え、段の区切りと1段の小節数、途中で拍子が変わる小節の作り方

  • 小節を足したい
  • 繰り返し（‖: :‖）と1番・2番カッコを付けたい
  • セーニョ・コーダ・D.S.・「%」を付けたい
  • セクション名を付けたい・順を入れ替えたい
  • 段の区切りを紙と同じにしたい
  • 途中で拍子が変わる小節を作りたい

小節を足したい

  1. 最後に足すなら、譜面の上のツールバーの「＋1小節」か「＋4小節」を押す
  2. 途中や先頭に足すなら、足したい所の隣の小節を長押しする。ツールバーの「選択」を押してから小節を押してもよい
  3. 「前に空の小節を追加」か「後ろに空の小節を追加」を押す
  4. 終えたら「選択をやめる」を押す
  • 選んだ小節と同じ数の、空の小節が入る。4小節を選んでいれば4小節入る
  • 入れた後も、選んだ小節は選ばれたまま。続けて押せる
  • コード入力画面で最後の小節にいるときは、「追加して次へ」でも1小節足せる
  • 「まとめて直す」の画面では、小節の間の「ここに追加」でも足せる
関係する項目
  • 小節を消したい・切り取りたい

繰り返し（‖: :‖）と1番・2番カッコを付けたい

  1. 繰り返しの始まりの小節を押し、「記号」タブを開く
  2. 「小節線」の「左」で「‖:」を押す
  3. 繰り返しの終わりの小節を開き、「小節線」の「右」で「:‖」を押す
  4. 1番カッコは、「カッコ（1番・2番）」で「1番の始まり」「1番の終わり」を、それぞれの小節で押す
  5. 1小節だけのカッコは「1番だけ」「2番だけ」を押す
  • 「記号」タブで押したものは、すぐその小節に付く。もう一度押すと外れる
  • 記号は1小節ずつ付ける。範囲を選んでまとめては付けられない
関係する項目
  • 記号に色を付けたい

セーニョ・コーダ・D.S.・「%」を付けたい

  1. 記号を付ける小節を押し、「記号」タブを開く
  2. 「記号」の欄で「セーニョ」か「コーダ」の札を押す
  3. to Coda や D.S. al Coda などの文字の記号も、同じ欄の札から押す
  4. 前の小節と同じ小節は、「同じ小節の繰り返し」で「%」（前の小節と同じ）か「%%」（前の2小節と同じ）を押す
  • Coda（飛び先）と to Coda（ここから飛ぶ）は、別の記号である
  • 「%」を付けた小節では、入れてあったコードは消えずに隠れる。「%」を外すと戻る
  • 演奏用の画面では、D.S. や to Coda を押すと飛び先のページへ移る
関係する項目
  • D.S. や to Coda から、飛び先のページへ移りたい

セクション名を付けたい・順を入れ替えたい

  1. セクションの頭の小節を押し、「記号」タブを開く
  2. 「セクション名」で A Verse などの札を押す
  3. 札に無い名前は「自分で書く」を押し、名前を打って「付ける」を押す
  4. セクションの順を変えるときは、譜面の画面の「…」の「セクションの並べ替え」を押す
  5. 動かしたいセクションの「≡」を押さえたまま、行きたい所まで動かす。上向き・下向きの矢印のボタンでも動かせる
  6. 「完了」を押す
  • セクション名を外すときは、付いている札をもう一度押す
  • 並べ替えも、「取り消す」で1回で戻せる

段の区切りを紙と同じにしたい

  1. 新しい段の頭にしたい小節を押し、「記号」タブを開く
  2. 「段の切れ目」で「ここから新しい段」を押す
  3. 元に戻すときは「続ける」を押す
  4. どの段も同じ小節数にするなら、「曲の設定」の「1段の小節数」で「4小節」か「8小節」を押す
  • 「ここから新しい段」は、紙には何も刷られない。画面だけに、付けた小節の印が出る
  • 「1段の小節数」の「中身で決める」では、歌詞やコードの量で1段の小節数が変わる

途中で拍子が変わる小節を作りたい

  1. 拍子が変わる小節を押し、「記号」タブを開く
  2. 「この小節の拍子」で拍子を押す
  3. 曲の拍子に戻すときは「曲に合わせる」を押す
  • 拍子記号は、前の小節と拍子が違う小節にだけ出る
  • 曲全体の拍子は「曲の設定」の「拍子」で変える
