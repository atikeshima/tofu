使い方

渡す・残す・見やすくする

PDF にして印刷する・送る方法、曲のファイルの渡し方と受け取り方、全部のバックアップ（控え）の保存、別の iPad への移し方と戻し方、歌詞を大きくする方法、記号に色を付ける方法

  • PDF にして印刷したい・送りたい
  • 曲をほかの人に渡したい・受け取りたい
  • 全部をバックアップ（控え）として保存したい
  • 別の iPad へ移したい・控えから戻したい
  • 歌詞を大きくしたい
  • 記号に色を付けたい

PDF にして印刷したい・送りたい

  1. 譜面の画面の右上の、四角から上向きの矢印が出た印（「共有」）を押す
  2. 「PDF 共有」を押す
  3. 「内容」で「コード＋歌詞」「コードのみ」「歌詞カード」「歌本スタイル」から選ぶ
  4. 要るなら「曲名と作詞・作曲を含める」「メモを含める」にチェックを入れる
  5. 「共有」を押す
  6. iPad の共有の画面で、印刷するか、送り先を選ぶ
  • 記号の組み合わせに食い違いがあると、「PDF を作成しました」と場所が出る。記号はそのまま刷られるので、演奏の前に確かめる
  • 歌詞が入りきらないときは、歌詞を少し小さくして刷る
  • 「曲名と作詞・作曲を含める」は、最後に選んだものが次も使われる
関係する項目

曲をほかの人に渡したい・受け取りたい

  1. 渡すときは、譜面の画面の右上の「共有」の印を押し、「ファイル共有」を押す
  2. iPad の共有の画面で、送り先を選ぶ
  3. 受け取るときは、メールやファイルアプリで受け取ったファイルを開き、開く先に Tofu を選ぶ
  4. Tofu の曲の一覧の「取り込む」の「曲のファイルから取り込む」で、ファイルを選んでもよい
  • 受け取った曲は、すぐ一覧に入る
  • 同じ名前の曲があると、番号が付く
  • 読めないファイルは、理由を出して断る。いまある曲は変わらない
  • 受け取る人の iPad にも、Tofu が入っている必要がある

全部をバックアップ（控え）として保存したい

  1. 曲の一覧の右上の、歯車の印（設定）を押す
  2. 「控え」の「すべてを書き出す」を押す
  3. iPad の共有の画面が開く。保存する場所（ファイルアプリの中など）を選ぶ
  4. 「「Tofu （日付と時刻）」を書き出しました」と出れば終わり
  • 入るのは、曲・PDF の譜面・セットリスト・設定のすべて。手書きと、配りかけの歌詞も入る
  • ファイルの名前は「Tofu 2026-10-16 19-05.tofu」のような形
  • 共有の画面でやめたときは、何も書き出さない
  • セットリスト1つを、中の曲と PDF ごと渡すときは「曲と PDF ごと書き出す」を使う。セットリストのタブの、行の「…」にある
関係する項目
  • 別の iPad へ移したい・控えから戻したい

別の iPad へ移したい・控えから戻したい

  1. 「全部をバックアップ（控え）として保存したい」の手順で、控えのファイルを作る
  2. そのファイルを、移す先の iPad へ送る。iPad どうしでファイルを渡す、ふだんの方法でよい
  3. 移す先の iPad で Tofu を開き、設定の「控え」の「控えを取り込む」を押して、そのファイルを選ぶ
  4. 「「（ファイル名）」を取り込みます」の画面で、曲・PDF の譜面・セットリストの件数を確かめる
  5. すでにあるものがあれば、扱いを1つ選ぶ
  6. 設定も移すなら「設定も戻す」を入れる
  7. 「取り込む」を押す。「上書きする」を選んだときは、確かめが出るので「置き換える」を押す
  • 「追加する（別のものとして追加）」：両方を残す。手元のものは消えない
  • 「上書きする（この iPad のものを置き換える）」：手元のものを、ファイルの中のもので置き換える。取り消せない
  • 「スキップ（この iPad のものを残す）」：手元のものをそのまま残す
  • 「すでにある」は、同じ曲かどうかで決まる。名前が同じだけの別の曲は、「すでにある」に数えない
  • 「設定も戻す」は、はじめは切ってある。人からもらったファイルで、自分の設定が替わらないようにするため
  • 読めないものが混ざっていても、読めるものは取り込む。読めないものは名前と理由が出る
  • iPad を買い替えたときは、ふつうは iPad 自身のバックアップから復元すれば、Tofu の中身も移る

歌詞を大きくしたい

  1. 曲の一覧の右上の、歯車の印（設定）を押す
  2. 「歌詞の大きさ」で「標準」「大」「特大」「最大」から選ぶ
  • 画面と PDF の両方に効く。歌詞カードと歌本スタイルにも効く
  • 歌詞を大きくすると、1段に入る小節が減ることがある
  • 曲には保存されない。この iPad での見え方である

記号に色を付けたい

  1. 曲の一覧の右上の、歯車の印（設定）を押す
  2. 「記号の色」で、「反復」「セーニョ」「コーダ」「終止」「セクション名」「1番・2番のカッコ」ごとに色を選ぶ
  3. 色を外すときは「なし」を押す。全部外すときは「すべてなしにする」を押す
  • 記号の後ろに、蛍光ペンのような色が付く。対になる記号を、遠くからでも見つけるためである
  • 同じ組の記号は、同じ色になる（例：セーニョと D.S.）
  • 画面と PDF の両方に出る
  • 曲には保存されない。曲を渡しても、相手の色は変わらない
