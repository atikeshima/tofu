PDF にして印刷したい・送りたい

  1. 譜面の画面の右上の ios_share（「共有」）を押す
  2. 「PDF 共有」を押す
  3. 「内容」で「コード＋歌詞」「コードのみ」「歌詞カード」「歌本スタイル」から選ぶ
  4. 要るなら「曲名と作詞・作曲を含める」「メモを含める」にチェックを入れる
  5. 要るなら「ファイル名」を書き換える。たとえば、キーを変えた PDF を別に送るときは、名前を変えておく 1.6.0 から
  6. 「共有」を押す
  7. iPad の共有の画面で、印刷するか、送り先を選ぶ
  • 「ファイル名」は、はじめは曲名。内容が「コード＋歌詞」でなければ、「曲名 (コードのみ)」のように内容が付く
  • 楽譜のアプリには、同じファイル名の PDF を上書きするものがある。キーを変えて送り分けるときは、名前を変える
  • アプリは、書き換えたファイル名を覚えない。次は、はじめの名前から始まる。「.pdf」は送るときに付く
  • 名前が空のとき、/ \ : * ? " < > | が入っているとき、長すぎるときは、「共有」を押せない。欄の下に理由が出る
  • D.S. があるのにセーニョが無い、のように記号の組み合わせが合わないと、「PDF を作成しました」の知らせに、合わない小節の場所が出る。記号は入れたまま刷られるので、演奏の前に確かめる
  • 歌詞が入りきらないときは、歌詞を少し小さくして刷る
  • 「曲名と作詞・作曲を含める」は、最後に選んだものが次も使われる

曲をほかの人に渡したい・受け取りたい

  1. 渡すときは、譜面の画面の右上の ios_share（「共有」）を押し、「ファイル共有」を押す
  2. iPad の共有の画面で、送り先を選ぶ
  3. 受け取るときは、メールやファイル App で受け取ったファイルを開き、開く先に Tofu を選ぶ
  4. Tofu の曲の一覧の「取り込む」の「曲のファイルから取り込む」で、ファイルを選んでもよい
  • 受け取った曲は、すぐ一覧に入る
  • 同じ名前の曲があると、曲名の後ろに「(2)」のような番号が付く
  • 読めないファイルは取り込まず、「曲のファイルとして読めませんでした：（名前）」と出る。いまある曲は変わらない。理由を見るときは、「曲のファイルから取り込む」で選び直す
  • 受け取る人の iPad にも、Tofu が入っている必要がある
  • ファイル App で2つ以上を選んで共有しても、Tofu に届くのは1つ目だけ。1つずつ共有する

iReal Pro に送りたい

このアプリで作った曲と、iReal Pro の入っている iPad

  1. 譜面の画面の右上の ios_share（「共有」）を押し、「iReal Pro に送る」を押す 1.6.0 から
  2. 「iReal Pro に写らないもの」（iReal Pro に送られないもの）と「変わるもの」が出ていれば、確かめる
  3. 1番の歌詞も送るときは、「歌詞も入れる（1番だけ）」にチェックを入れる
  4. 「送る」を押す。iReal Pro が開き、曲が入る
  • キーは、いま画面に出ているキーで送る。移調していれば、移調した後のキーで入る
  • iReal Pro では、1小節の中でコードを置ける場所が4つしかない（4/4 なら各拍の頭）。そこから外れたコード（2拍目の裏など）は、少し前の場所へずらして送る
  • ずらすコードは、送る前の画面の「変わるもの」に「3小節目：G7 を前の拍に寄せます」のように出る
  • 1小節に5つ以上コードがあるときは、5つ目からのコードは送られない。曲のほかの所は送られる
  • テンポ・作詞・発表年・メモ・2番以降の歌詞・手書き・シンコペーション・色・段の切れ目などは、iReal Pro に送られない
  • 伴奏の種類（スタイル）は「Medium Swing」で入る。iReal Pro の側で直せる
  • 長い歌詞は切って送る。iReal Pro では、字が隣の小節と重なることがある
  • iReal Pro が入っていないと、「iReal Pro を開けませんでした。…」と出る
  • 1曲ずつ送る。セットリストをまとめては送れない

全部をバックアップ（控え）として保存したい

  1. 曲の一覧の右上の、設定のアイコン（settings）を押す
  2. 「控え」の「すべてを書き出す」を押す
  3. iPad の共有の画面が開く。保存する場所（ファイル App の中など）を選ぶ
  4. 「「Tofu （日付と時刻）」を書き出しました」と出れば終わり
  • 入るのは、曲・PDF の譜面・セットリスト・設定のすべて。手書きと、歌詞の帯に残っている（まだ入れていない）歌詞も入る
  • ファイルの名前は「Tofu 2026-10-16 19-05.tofu」のような形
  • 共有の画面でやめたときは、何も書き出さない
  • セットリスト1つを、中の曲と PDF ごと渡すときは「曲と PDF ごと書き出す」を使う。セットリストのタブの、行の more_horiz にある

別の iPad へ移したい・控えから戻したい

  1. 「全部をバックアップ（控え）として保存したい」の手順で、控えのファイルを作る
  2. そのファイルを、移す先の iPad へ送る。AirDrop・メール・iCloud Drive など、ふだんの方法でよい
  3. 移す先の iPad で Tofu を開き、設定の「控え」の「控えを取り込む」を押して、そのファイルを選ぶ
  4. 「「（ファイル名）」を取り込みます」の画面で、曲・PDF の譜面・セットリストの件数を確かめる
  5. すでにあるものがあれば、扱いを1つ選ぶ
  6. 設定も移すなら「設定も戻す」をオンにする
  7. 「取り込む」を押す。「上書きする」を選んだときは、確認が出るので「置き換える」を押す
  • 「追加する（別のものとして追加）」：両方を残す。手元のものは消えない
  • 「上書きする（この iPad のものを置き換える）」：手元のものを、ファイルの中のもので置き換える。取り消せない
  • 「スキップ（この iPad のものを残す）」：手元のものをそのまま残す
  • 「すでにある」に数えるのは、この iPad にある曲と、もとが同じ曲だけ。名前が同じでも、別に作った曲は数えない
  • 「設定も戻す」は、はじめはオフ。人からもらったファイルで、自分の設定が替わらないようにするため
  • 読めないものが混ざっていても、読めるものは取り込む。読めないものは名前と理由が出る
  • iPad を買い替えたときは、ふつうは iPad 自身のバックアップから復元すれば、Tofu の中身も移る

歌詞を大きくしたい

  1. 曲の一覧の右上の、設定のアイコン（settings）を押す
  2. 「歌詞の大きさ」で「標準」「大」「特大」「最大」から選ぶ
  • 画面と PDF の両方に効く。歌詞カードと歌本スタイルにも効く
  • 歌詞を大きくすると、1段に入る小節が減ることがある
  • 曲には保存されない。この iPad での見え方である

コードの字を手書き風にしたい

  1. 曲の一覧の右上の、設定のアイコン（settings）を押す
  2. 「コードの字」で「標準」か「手書き風」を押す
  • 手書き風は、ジャズの手書きの譜面に近い字
  • コードと一緒に、セーニョ・コーダ・D.S.・to Coda などの記号、カッコの番号、拍子も手書き風になる 1.6.0 から
  • 歌詞・セクション名・曲名・メモは、今の字のまま
  • 画面と PDF の両方に効く。歌本スタイルと演奏用の画面にも効く
  • 曲には保存されない。この iPad での見え方である

記号に色を付けたい

  1. 曲の一覧の右上の、設定のアイコン（settings）を押す
  2. 「記号の色」で、「反復」（リピート記号 ‖: :‖）「セーニョ」「コーダ」「終止」（Fine・D.C. al Fine）「セクション名」「1番・2番のカッコ」ごとに色を選ぶ
  3. 色を外すときは「なし」を押す。全部外すときは「すべてなしにする」を押す
  • 記号の後ろに、蛍光ペンのような色が付く。対になる記号を、遠くからでも見つけるためである
  • 同じ組の記号は、同じ色になる（例：セーニョと D.S.）
  • 画面と PDF の両方に出る
  • 曲には保存されない。曲を渡しても、相手の色は変わらない

Tofu 灯譜 は、コードと歌詞だけの譜面を作る iPad の無料アプリです。手元の楽譜を書き写して移調し、PDF の譜面と一緒にセットリストで演奏できます。広告なし・登録なし。
