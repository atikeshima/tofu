使い方

やりたいことから探してください。各ページは、画面に出るボタンの名前で手順を書いています。

「1.4.0 から」の印は、バージョン 1.4.0 で入るものです。

はじめる

  • 新しい曲を作りたい
  • 曲を探したい・並べ替えたい
  • 曲名・キー・拍子・テンポを直したい
  • 曲を複製したい・削除したい
  • 読み込めなかった曲があると出た
  • 使い方の曲を、もう一度一覧に入れたい
  • 案内やヒントを、もう一度見たい
  • この使い方を、アプリから開きたい 1.4.0 から

コードを入れたい

  • コードを1つ入れたい
  • 続けて、次の小節にも入れたい
  • 紙にある「C7(♭9)」「C/E」のようなコードを入れたい
  • コードの拍の位置を直したい・シンコペーションを付けたい
  • コードを文字でまとめて打ちたい
  • コードの書き方（ジャズ式と標準表記）を変えたい

歌詞を入れたい

  • 1小節ずつ歌詞を打ちたい
  • 歌詞をまとめて貼り付けて、小節に配りたい
  • 歌詞の切れ目が1小節ずれているのを直したい
  • 弱起の歌詞を、小節の右端に寄せたい

記号と小節の形を整えたい

  • 小節を足したい
  • 繰り返し（‖: :‖）と1番・2番カッコを付けたい
  • セーニョ・コーダ・D.S.・「%」を付けたい
  • セクション名を付けたい・順を入れ替えたい
  • 段の区切りを紙と同じにしたい
  • 途中で拍子が変わる小節を作りたい

譜面を直したい

  • 小節をコピーして貼り付けたい
  • 小節を消したい・切り取りたい
  • 間違えた操作を戻したい
  • 譜面に手書きでメモしたい
  • 歌い手に合わせてキーを変えたい
  • ツールバーが消えた

紙の楽譜を取り込みたい

  • PDF の楽譜を取り込みたい
  • 紙の楽譜をカメラで撮って取り込みたい
  • 取り込んだページを並べ替えたい・余白を切りたい
  • 紙のコード譜を、編集できる曲として取り込みたい（AI を使う）
  • PDF の譜面の名前を変えたい・人に渡したい

本番で演奏したい

  • 演奏用の画面で、ページをめくりたい
  • 演奏メニューを出したい・表示を変えたい
  • D.S. や to Coda から、飛び先のページへ移りたい
  • 譜面を大きく見たい
  • メトロノームを鳴らしたい
  • チューナーで音を合わせたい
  • PDF の譜面に書き込みたい

セットリストで本番に備えたい

  • セットリストを作りたい
  • その日だけ、曲のキーを変えたい
  • セットリストで演奏したい・途中で曲を替えたい

渡す・残す・見やすくする

  • PDF にして印刷したい・送りたい
  • 曲をほかの人に渡したい・受け取りたい
  • 全部をバックアップ（控え）として保存したい
  • 別の iPad へ移したい・控えから戻したい
  • 歌詞を大きくしたい
  • 記号に色を付けたい
