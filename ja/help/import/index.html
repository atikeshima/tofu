使い方

紙の楽譜を取り込みたい

PDF の楽譜の取り込み、紙の楽譜をカメラで撮る・写真から取り込む方法、取り込んだページの並べ替え・余白の切り取り・回転・斜めの直し・くっきりさせる方法、紙のコード譜を AI で編集できる曲にする方法、PDF の譜面の名前の変更と共有

  • PDF の楽譜を取り込みたい
  • 紙の楽譜をカメラで撮って取り込みたい
  • 取り込んだページを並べ替えたい・余白を切りたい
  • 紙のコード譜を、編集できる曲として取り込みたい（AI を使う）
  • PDF の譜面の名前を変えたい・人に渡したい

PDF の楽譜を取り込みたい

  1. 曲の一覧の右上の「取り込む」を押す
  2. 「PDF の譜面」の「PDF を取り込む（ファイルから）」を押す
  3. ファイルを選ぶ画面で、PDF を選ぶ。いくつでも選べる
  4. 「ページの確認」の画面が開く。「名前」とページの並びを確かめる
  5. 右上の「完了」を押す
  • 2つ以上の PDF を選んだときは、「ページの確認」の画面は出ない。取り込んだ数が出る
  • 取り込みをやめるときは、「ページの確認」の左上の「キャンセル」を押し、「取り込みをやめる」を押す
  • PDF の譜面は、移調できない。コードを入れ直す曲にはならない
  • 一覧の PDF の譜面を押すと、すぐ演奏用の画面が開く
関係する項目
  • 取り込んだページを並べ替えたい・余白を切りたい

紙の楽譜をカメラで撮って取り込みたい

  1. 曲の一覧の右上の「取り込む」を押し、「カメラで撮る」を押す。撮ってある写真なら「写真から選ぶ」
  2. ページを続けて撮る。撮り終えたら、iPad のスキャンの画面を終える
  3. 「写真をくっきりさせますか？」と出たら、「くっきりさせる」か「そのまま」を押す
  4. カメラで撮ったときは「写真アプリにも保存しますか？」と出る。「保存する」か「保存しない」を押す
  5. 「ページの確認」の画面で、名前とページを確かめ、「完了」を押す
  • 「くっきりさせる」は、紙を白く、鉛筆の線を濃くする。迷ったら「そのまま」でよい。後からページごとに直せる
  • くっきりさせている間に「くっきりさせずに取り込む」を押すと、元の写真のまま取り込む
  • 「キャンセル」を押すと、取り込みそのものをやめる
  • 書類のスキャンが使えない iPad では、「カメラで撮る」は出ない
  • 1回に撮れる枚数には、iPad の書類のスキャンの上限がある（24枚で止まった）。続きは、「ページの確認」の画面の「カメラで撮って追加」で足せる

取り込んだページを並べ替えたい・余白を切りたい

  1. 一覧で PDF の譜面を押す。演奏用の画面が開く
  2. 左右の端（約3cm）より内側を押して演奏メニューを出し、「ページの編集」を押す
  3. 並べ替えるときは、ページの下の「≡」を押さえたまま、移したい所まで動かす
  4. 余白を切るときは、ページの下の「余白を切り取る」を押す。かぎ形が2つ重なった印のボタン
  5. 枠の角や辺を動かして残す範囲を決め、「完了」を押す
  6. 回す・斜めを直す・くっきりさせる・撮り直す・消すときは、ページの下の「…」を押して選ぶ
  7. 終えたら右上の「完了」を押す
  • 「…」の中は「前へ」「後ろへ」「左に回転」「右に回転」「斜めを直す」「くっきりさせる」「撮り直す」「このページを削除」
  • 余白は「すべてのページに適用」で、全部のページを同じ枠で切れる
  • 全部のページをくっきりさせるなら「すべてのページをくっきりさせる」を押す
  • ページを足すときは「カメラで撮って追加」か「写真から追加」を押す
  • どの直しも、元の PDF は変わらない。取り消し・やり直しもできる
  • 左上の「キャンセル」を押すと、開いてから変えたものを全部戻す
  • ページの絵を押すと、大きく見られる。見出しの「‹」「›」で前後のページへ送れる 1.4.0 から
関係する項目

紙のコード譜を、編集できる曲として取り込みたい（AI を使う）

  1. 曲の一覧の右上の「取り込む」を押し、「AI から取り込む」を押す
  2. 「プロンプトをコピー」を押す
  3. 使っている AI のアプリやサイトに、コピーした文を貼り付け、手元の譜面の写真と一緒に渡す
  4. AI の返事を、最初から最後までコピーする。返事のデータは、手直しせずにそのままコピーする
  5. Tofu に戻り、「AI の返事を貼り付ける」を押す
  6. 「取り込む内容」で、曲名・原調・小節の数を確かめ、右上の「取り込む」を押す
  7. 曲の譜面が開く。曲名やコードを、元の譜面と見比べる
  • アプリは AI と直接やりとりしない。AI に渡すのは、自分の操作である
  • 「直したところ（数件）」が出たら、見比べるときに先にそこを見る
  • 貼り間違えたときは「貼り直す」を押す
  • 取り込めないときは「取り込めませんでした（数件）」と理由が出る。いまある曲は何も変わらない
  • 理由は「理由を全部コピー」でコピーできる

PDF の譜面の名前を変えたい・人に渡したい

PDF の譜面。このアプリで作った曲は「曲名・キー・拍子・テンポを直したい」を見る

  1. 一覧で PDF の譜面を押す。演奏用の画面が開く
  2. 左右の端（約3cm）より内側を押して演奏メニューを出す
  3. 名前を変えるときは「ページの編集」を押し、「名前」を打ち直して「完了」を押す
  4. 人に渡すときは「共有」を押す。iPad の共有の画面で、送り先を選ぶ
  5. 演奏用の画面を閉じるときは、演奏メニューの右の端の「閉じる」を押す
  • 共有では、切り取りと書き込みを重ねた PDF を渡す。元の PDF そのものは渡さない
  • 細い窓では、「ページの編集」と「共有」は演奏メニューの「…」の中にある
  • 複製と削除は、曲の一覧の行の右端の「…」からできる
  • 後から名前を変えたときは、同じ名前があっても番号は付かない
関係する項目
