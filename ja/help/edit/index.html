使い方

譜面を直したい

小節のコピーと貼り付け、小節の削除と切り取り、操作の取り消しとやり直し、手書きのメモ、キーの上げ下げ（移調）、ツールバー（「＋4小節」などの列）が消えたときの戻し方

  • 小節をコピーして貼り付けたい
  • 小節を消したい・切り取りたい
  • 間違えた操作を戻したい
  • 譜面に手書きでメモしたい
  • 歌い手に合わせてキーを変えたい
  • ツールバーが消えた

小節をコピーして貼り付けたい

  1. コピーしたい小節を長押しする。ツールバーの「選択」を押してから小節を押してもよい
  2. 何小節も選ぶときは、選んだまま小節を指で横になぞる
  3. 「コピー」を押す。「（数）小節をコピーしました」と出る
  4. 貼りたい所の直前の小節を押す。その1小節が選ばれ直す
  5. 「直後に貼り付け」を押す。選んだ小節の後ろに入る
  6. 終えたら「選択をやめる」を押す
  • 「直後に貼り付け」は、間に入れる操作である。後ろの小節は消えずに後ろへずれる
  • 選んだ小節を置き換えたいときは、「選択範囲に上書き」を押す。確かめが出たら「上書きする」を押す
  • 画面の外の小節まで選ぶときは、譜面を送ってから、最後の小節を長押しする
  • 手書きはコピーされない
  • 範囲を選び始めると、選び方の短い説明が出る
関係する項目
  • 小節を消したい・切り取りたい

小節を消したい・切り取りたい

  1. 消したい小節を長押しして選ぶ。何小節もなら、横になぞって範囲を選ぶ
  2. 消すときは「削除」を押す。「選んだ小節を削除しますか？」と出たら「削除」を押す
  3. 別の所へ移すときは「切り取り」を押す。選んだ小節が消え、貼り付けられる状態になる
  4. 移したい所の直前の小節を長押しして選び、「直後に貼り付け」を押す
  • 曲の小節を全部消すことはできない。1小節以上は残す
  • 消した小節は、「取り消す」で戻せる
  • 1つのコードだけを消すときは、コード入力画面の「このコードを削除」を使う
関係する項目
  • 小節をコピーして貼り付けたい
  • 間違えた操作を戻したい

間違えた操作を戻したい

  1. 譜面の画面の右上の、左向きに曲がった矢印のボタン（「取り消す」）を押す
  2. 戻しすぎたら、その隣の右向きに曲がった矢印のボタン（「やり直す」）を押す
  • 20回前まで戻れる
  • コード入力画面の上にも、同じ2つのボタンがある
  • 別の曲を開いたときや、アプリを終えたときに、戻せる記録は消える

譜面に手書きでメモしたい

  1. 譜面の画面の上の「テキスト」「手書き」の切り替えで、「手書き」を押す
  2. 手書きのツールバーに、ペンが3本並ぶ。ペンは、引いた線の見本で出る
  3. ペンを押して、譜面に書く
  4. 消すときは「消しゴム」を押し、消したい所をなぞる
  5. 選んでいるペンをもう一度押すと、「色」「太さ」「濃さ」を変えられる
  6. 書き終えたら「テキスト」を押す
  • 手書きの間は、2本の指で譜面を送る。1本の指は書く操作になる
  • 手書きを全部消すときは「手書きをすべて削除」を押す。「取り消す」で戻せる
  • 手書きは、譜面の組み方が変わっても動かない。位置が合わなくなったら、消して書き直す
  • ペンの設定は、どの曲でも同じものが使われる
関係する項目
  • PDF の譜面に書き込みたい

歌い手に合わせてキーを変えたい

  1. 譜面の上のツールバーの「移調」の両側のボタンを押す
  2. マイナスの印（−）で半音下げ、プラスの印（＋）で半音上げる
  3. 元のキーに戻すときは「原調へ戻す」を押す
  • 保存してあるコードは、元のキーのまま。出し方だけが変わる
  • 移調すると、♯ と ♭ はキーに合わせた書き方になる
  • 移調したまま入れたコードも、元のキーに直して保存される
  • セットリストでは、その日だけキーを変えられる
関係する項目
  • その日だけ、曲のキーを変えたい

ツールバーが消えた

  1. 譜面を、いちばん上の端まで戻す。ツールバー（「＋4小節」「まとめて直す」などの列）が、また出る
  2. いつも出しておくなら、譜面の画面の「…」を押す
  3. 「ツールバーを常に表示」にチェックを入れる
  • ツールバーは、譜面を先へ送ると隠れる。譜面を広く見るためである
  • 選択中のボタンの列と、手書きのツールバーは隠れない
  • ツールバーが隠れたとき、譜面の上の端に戻し方の説明が出る。「OK」を押すと、次からは出ない 1.4.0 から

Tofu 灯譜 は、コードと歌詞だけの譜面を作る iPad の無料アプリです。手元の楽譜を書き写して移調し、PDF の譜面と一緒にセットリストで演奏できます。広告なし・登録なし。
