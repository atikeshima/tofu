使い方

はじめる

新しい曲の作り方、曲の探し方と並べ替え、曲名・キー・拍子・テンポの直し方、曲の複製と削除、読み込めなかった曲の扱い、使い方の曲の入れ直し、案内やヒントをもう一度見る方法、この使い方の開き方

  • 新しい曲を作りたい
  • 曲を探したい・並べ替えたい
  • 曲名・キー・拍子・テンポを直したい
  • 曲を複製したい・削除したい
  • 読み込めなかった曲があると出た
  • 使い方の曲を、もう一度一覧に入れたい
  • 案内やヒントを、もう一度見たい
  • この使い方を、アプリから開きたい 1.4.0 から

新しい曲を作りたい

  1. 曲の一覧の右上の「新しい曲」を押す。細い窓では、プラスの印（＋）だけのボタンになる
  2. 「曲名」に名前を打つ。はじめから「無題」が入っていて、打つと置き換わる
  3. 「作成」を押す。小節の無い譜面が開く
  4. 譜面の上のツールバーの「＋4小節」を押して、小節を足す
  • 小節が無い間は、譜面の真ん中にも「＋4小節」が出る 1.4.0 から
  • 名前を空のまま作ると「無題」になる
  • 同じ名前の曲があると、「いろは (2)」のように番号が付く
  • 曲が1つも無い一覧では、真ん中に「新しい曲」と「サンプル曲を追加する」が出る 1.4.0 から
関係する項目
  • コードを1つ入れたい
  • 小節を足したい

曲を探したい・並べ替えたい

  1. 曲の一覧の上の「曲名で探す」の欄に、曲名の一部を打つ
  2. 打つそばから、その字を含む曲だけが残る
  3. 並び順を変えるときは、欄の横の並べ替えの印を押す。横線が3本並び、下ほど短い印
  4. 「最近開いた順」「更新日（新しい順）」「名前（A→Z）」などから選ぶ
  • 大文字と小文字は区別しない
  • ひらがなとカタカナは区別する。「いろは」と打っても「イロハ」は出ない
  • 漢字の曲名は、読みの順には並ばない
  • PDF の譜面も、曲と同じ一覧に並ぶ

曲名・キー・拍子・テンポを直したい

このアプリで作った曲。PDF の譜面は「PDF の譜面の名前を変えたい・人に渡したい」を見る

  1. 譜面の画面のいちばん上の曲名を押す。その下の情報の行（キー・拍子・小節数）を押してもよい
  2. 「曲の設定」が開く。「…」の「曲の設定」からも開ける
  3. 「曲名」「原調」「拍子」「テンポ」を直す。「作詞」「作曲」「発表年」「メモ」もここで入れる
  4. テンポが無い曲は「テンポを付ける」を押す。60 から始まり、マイナスの印（−）とプラスの印（＋）で1ずつ変わる
  5. 直し終えたら「完了」を押す
  • 「原調」を変えても、コードの音は動かない。「原調」は、この曲が何調かを書いておく欄である
  • キーを上げ下げして弾くときは「歌い手に合わせてキーを変えたい」（edit）を見る
  • テンポを消すときは「テンポを外す」を押す
関係する項目
  • コードの書き方（ジャズ式と標準表記）を変えたい
  • 段の区切りを紙と同じにしたい
  • PDF の譜面の名前を変えたい・人に渡したい

曲を複製したい・削除したい

  1. 曲の一覧で、曲の行の右端の「…」の印を押す
  2. 複製するときは「複製」を押す。名前の後ろに「のコピー」が付いた曲ができる
  3. 削除するときは「削除」を押す
  4. 「曲を削除しますか？」と出たら、「削除」を押す
  • 並び順が「最近開いた順」なら、複製した曲は元の曲のすぐ下に出る
  • 削除は取り消せない
  • PDF の譜面も、同じ「…」から複製・削除できる
  • セットリストに入れていた曲を消しても、セットリストの行は残る。「見つからない曲（曲名）」と出る
関係する項目
  • セットリストを作りたい

読み込めなかった曲があると出た

曲の一覧の上に「読み込めなかった曲が（数）件あります」と出ているとき

  1. 「読み込めなかった曲が（数）件あります」の帯を押す
  2. 「読み込めなかった曲」の画面が開く。曲ごとに、読めなかった理由が出る
  3. 手で直す見込みがあるなら、先に「曲のデータをコピー」を押して、中身を残しておく
  4. 要らない曲は「削除」を押す。「この曲を削除しますか？」と出たら「削除」を押す
  • アプリは、読めない曲を黙って消さない。消すかどうかは自分で決める
  • 理由に「新しいバージョン」と出ているときは、App Store で Tofu をアップデートする
  • 読めない PDF の譜面は、一覧に「読めない PDF の譜面」と出る。押すと理由が出て、「OK」か「削除」を選べる
  • 読めないセットリストは、「読めないセットリスト」と出る
関係する項目
  • 曲をほかの人に渡したい・受け取りたい

使い方の曲を、もう一度一覧に入れたい

  1. 曲の一覧の右上の、歯車の印（設定）を押す
  2. 「サンプル曲」の「サンプル曲を追加する」を押す
  3. 「とうふの つかいかた」と「How to use Tofu」の2曲が一覧に入る
  • 前から入っている曲は変わらない
  • 同じ名前の曲があると、番号が付く
  • 曲が1つも無い一覧では、真ん中の「サンプル曲を追加する」でも入れられる 1.4.0 から

案内やヒントを、もう一度見たい

  1. 曲の一覧の右上の、歯車の印（設定）を押す
  2. 「ヒントをもう一度出す」を押す
  3. 「ヒントをもう一度出すようにしました」と出る
  • 一度消したヒントが、それぞれの画面でまた出る
  • 演奏用の画面などで出る吹き出しも、また出る 1.4.0 から
  • はじめの道（最初に起動したときの案内）は、次にアプリを起動したときに、また始まる 1.4.0 から
  • はじめの道は、1枚目の「スキップ」でやめられる。暗い所を押してもやめられる 1.4.0 から
関係する項目
  • ツールバーが消えた

この使い方を、アプリから開きたい 1.4.0 から

  1. 曲の一覧の右上の、丸に「?」の印を押す
  2. 設定の「使い方」を押しても開く
  3. 譜面の画面の「…」の「使い方」を押すと、譜面の直し方のページが開く
  4. 読み終えたら、左上の「完了」を押してアプリに戻る
  • ページを読むには、インターネットにつながっている必要がある
  • アプリの言葉が日本語なら日本語のページ、それ以外なら英語のページが開く
