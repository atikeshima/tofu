使い方

セットリストで本番に備えたい

セットリストの作り方、曲の足し方・並べ替え・外し方、その日だけキーを変える方法、セットリストで演奏する方法、演奏の途中で曲を替える方法

  • セットリストを作りたい
  • その日だけ、曲のキーを変えたい
  • セットリストで演奏したい・途中で曲を替えたい

セットリストを作りたい

  1. 曲の一覧の上の「セットリスト」タブを押す
  2. 「新しいセットリスト」を押し、「セットリストの名前」を打って「作成」を押す
  3. 画面が広いときは、右に曲と PDF の譜面の一覧が出る。曲を押すと、最後に足される
  4. 画面が狭いときは「曲を追加」を押し、曲を選んで「（数）曲を追加」を押す
  5. 順番は、行の左の「≡」を押さえたまま動かす。上向き・下向きの矢印のボタンでも動かせる
  6. 「完了」を押す
  • 同じ曲を2回入れられる。入っている曲には「✓ 1曲目」のように出る
  • 行を外すときは、ごみ箱の印（「セットリストから削除」）を押す。確かめは出ないが、「取り消す」で戻せる
  • 後から直すときは、セットリストを開いて「編集」を押す
  • 名前の変更・複製・削除は、セットリストのタブの行の右端の「…」からできる
  • セットリストが無いタブでは、真ん中に「新しいセットリスト」が出る 1.4.0 から

その日だけ、曲のキーを変えたい

  1. セットリストを開き、「編集」を押す
  2. 曲の行の「キー（音名）」を押す
  3. 「曲のキーのまま」か、12のキーから選ぶ
  4. 「完了」を押す
  • 曲そのものは書き換わらない。キーはセットリストにだけ残る
  • 演奏の途中でも、演奏メニューの「キー」で変えられる
  • PDF の譜面の行には、キーは出ない
関係する項目
  • 歌い手に合わせてキーを変えたい

セットリストで演奏したい・途中で曲を替えたい

  1. セットリストを開き、「演奏」を押す。1曲目から開く
  2. 途中の曲から始めるときは、その曲の行を押す。その曲の1ページ目から開く
  3. ページは、曲をまたいで続けてめくれる
  4. 曲を替えるときは、画面の下の端の曲名の帯を押す。曲の一覧が出るので、替えたい曲を押す
  • 演奏メニューの「曲」でも、曲の一覧が出る
  • 下の端には、何曲目か・曲名・キー・ページが出る
  • 初めて開いたときは、曲名の帯を吹き出しで指す 1.4.0 から
関係する項目
  • 演奏用の画面で、ページをめくりたい
