使い方

セットリストで本番に備えたい

セットリストの作り方、曲の足し方・並べ替え・外し方、名前の順などで並べる方法、その日だけキーを変える方法、セットリストで演奏する方法、演奏の途中で曲を替える方法

  • セットリストを作りたい
  • セットリストの曲を、名前の順などで並べたい
  • その日だけ、曲のキーを変えたい
  • セットリストで演奏したい・途中で曲を替えたい

セットリストを作りたい

  1. 曲の一覧の上の「セットリスト」タブを押す
  2. 「新しいセットリスト」を押し、「セットリストの名前」を打って「作成」を押す
  3. 横向きのときなど、画面の幅が広いときは、右に曲と PDF の譜面の一覧が出る。曲を押すと、最後に足される
  4. 縦向きのときなど、画面の幅が狭いときは「曲を追加」を押し、曲を選んで「（数）曲を追加」を押す
  5. 順番は、行の左の drag_handle を押さえたまま動かす。arrow_upward arrow_downward のボタンでも動かせる
  6. 「完了」を押す
  • 同じ曲を2回入れられる。右の一覧では、入っている曲に「✓ 1曲目」のように出る
  • 行を外すときは、delete_outline（「セットリストから削除」）を押す。確認は出ないが、上のバーの undo（「取り消す」）で戻せる
  • 後から直すときは、セットリストを開いて「編集」を押す
  • 名前の変更・複製・削除は、セットリストのタブの行の右端の more_horiz からできる
  • セットリストが無いタブでは、真ん中に「新しいセットリスト」が出る。曲も PDF の譜面も無いときは、代わりに曲の一覧へ移るボタン（「曲」のタブへ）が出る
  • 右の一覧と「曲を追加」の画面でも、並べ替えのアイコン（sort）で並び順を選べる。ここで選ぶのは、足す曲を探すための一覧の並び。選んだ並び順は、次に曲を追加するときも同じになる。セットリストの曲順も、曲の一覧の並び順も変わらない 1.6.0 から
関係する項目
  • セットリストの曲を、名前の順などで並べたい

セットリストの曲を、名前の順などで並べたい

  1. セットリストを開き、「編集」を押す 1.6.0 から
  2. 上のバーの並べ替えのアイコン（sort）を押す
  3. 「名前（A→Z）」「作成日（新しい順）」「更新日（新しい順）」などから選ぶ
  4. 元の並びに戻すときは、同じ所で「手で並べた順」を選ぶ
  5. 「完了」を押す
  • 並べ方を選び直すだけなら、手で並べた順は消えない。「手で並べた順」を選べば、いつでも戻る
  • 名前順などで並べている間は、一覧の上に「名前（A→Z）で並べています」のように出る。演奏も、その順になる
  • 名前順などで並べている間に、行を動かすか曲を足すと、「いま見えている並びを、手で並べた順にしますか？…」と出る。名前順などの並びが、手で並べた順と同じときは、失うものが無いので出ない
  • この確認で「そうする」を押すと、見えている並びが新しい手で並べた順になり、前の手で並べた順は消える。「キャンセル」なら何も変わらない
  • 並べ方を変えたのも、undo（「取り消す」）で戻せる
関係する項目
  • セットリストで演奏したい・途中で曲を替えたい

その日だけ、曲のキーを変えたい

  1. セットリストを開き、「編集」を押す
  2. 曲の行の、キーのボタン（例：「曲のキーのまま（G）」）を押す
  3. 「曲のキーのまま（G）」か、12のキーから選ぶ。選んだ行のボタンは「キー A（+2）」のようになる。（+2）は、曲のキーから半音2つ上という意味
  4. 「完了」を押す
  • 曲そのものは書き換わらない。キーはセットリストにだけ残る
  • 演奏の途中でも、演奏メニューの「キー」で変えられる
  • PDF の譜面の行には、キーは出ない
関係する項目
  • 歌い手に合わせてキーを変えたい

セットリストで演奏したい・途中で曲を替えたい

  1. セットリストを開き、「演奏」を押す。1曲目から開く
  2. ページは、曲をまたいで続けてめくれる
  3. 曲を替えるときは、画面の下の端の曲名を押す。曲の一覧が出るので、替えたい曲を押す
  • 途中の曲から始めるときは、「演奏」の代わりに、その曲の行を押す。その曲の1ページ目から開く
  • 演奏メニューの「曲」でも、曲の一覧が出る
  • 下の端には、何曲目か・曲名・キー・ページが出る
  • 初めて演奏用の画面を開いたときは、めくり方の吹き出しが出る。下の端の曲名を指す吹き出しは、その後にセットリストで演奏するときに出る
関係する項目
  • 演奏用の画面で、ページをめくりたい
前のページ本番で演奏したい次のページ渡す・残す・見やすくする
Tofu 灯譜 は、コードと歌詞だけの譜面を作る iPad の無料アプリです。手元の楽譜を書き写して移調し、PDF の譜面と一緒にセットリストで演奏できます。広告なし・登録なし。
