これまでの変更

版ごとに、変わったことをまとめています。新しい版が上です。

1.6.0 （2026-10-28）

  • iReal Pro などが書き出した MusicXML から、曲を取り込める。iReal Pro の共有からも取り込める → iReal Pro などの曲を、MusicXML から取り込みたい
  • 作った曲を、iReal Pro に送れる → iReal Pro に送りたい
  • PDF を共有するとき、ファイル名を変えられる → PDF にして印刷したい・送りたい
  • 2小節の繰り返し（%%）の記号を、2つの小節の間に「2」を付けて表示する。この2小節は、選ぶ・消す・コピーするときに一緒に動く → セーニョ・コーダ・D.S.・「%」を付けたい
  • セクションの切れ目が段の変わり目と重なるとき、前の段の終わりと次の段の始まりの両方に複縦線（‖）を引く。段の始まりの小節に自分で入れた複縦線が出ないことがあったのを直した → セクション名を付けたい・順を入れ替えたい／段の区切りを紙と同じにしたい
  • コードの字を「手書き風」にしているとき、セーニョ・コーダ・D.S. などの記号と拍子記号も手書き風で表示する → コードの字を手書き風にしたい
  • セットリストの曲を、名前の順・作成日の順・更新日の順に並べ替えられる。手で並べた順にも戻せる → セットリストの曲を、名前の順などで並べたい
  • セットリストに曲を追加するときの一覧で選んだ並び順を、次に追加するときも使う。曲の一覧の並び順は変わらない → セットリストを作りたい
  • 小さいメトロノームに、いまのテンポ（数字）をいつも表示する。数字を押すと打ち直せる → メトロノームを鳴らしたい
  • 12/8 のように上と下の数字の桁数が違う拍子記号で、下の数字が左に寄っていたのを、真ん中にそろえた
  • Tofu を終了しているときに、ほかのアプリから Tofu へ共有したファイルが取り込まれないことがあったのを直した → 曲をほかの人に渡したい・受け取りたい
  • iPad を横にして小節を押したとき、右に開くコード入力の画面に、その小節が隠れることがあったのを直した → コードを1つ入れたい

1.5.0 （2026-10-23）

  • 暗い表示：暗い部屋で、地を暗く、字を明るくして演奏できる → 演奏メニューを出したい・表示を変えたい
  • コードの字を「手書き風」にできる → コードの字を手書き風にしたい
  • 「余白を消す」で、紙の上下の余白を消して譜面を大きく見られる → 譜面を大きく見たい
  • 曲の検索で、ひらがなとカタカナ、全角と半角を区別しない → 曲を探したい・並べ替えたい
  • 手を加えていない PDF の譜面は、元の PDF のまま共有する → PDF の譜面の名前を変えたい・人に渡したい
  • マイクやカメラが使えないとき、「設定を開く」から許可できる → チューナーで音を合わせたい／紙の楽譜をカメラで撮って取り込みたい
  • 細い窓でも、メトロノームとチューナーを演奏メニューに残す → 演奏メニューを出したい・表示を変えたい
  • 止めている小窓のメトロノームを「×」で閉じられる → メトロノームを鳴らしたい
  • 1小節にコードが入りきらないときも、字を落とさずに小さくして描く → コードを1つ入れたい
  • ベース音だけが変わるときは、「C」「/B」のように斜線とベース音だけを書く → コードを1つ入れたい
Tofu 灯譜 は、コードと歌詞だけの譜面を作る iPad の無料アプリです。手元の楽譜を書き写して移調し、PDF の譜面と一緒にセットリストで演奏できます。広告なし・登録なし。
