使い方

コードを入れたい

コードの入れ方、続けて次の小節に入れる方法、C7(♭9) や C/E（分数コード）や N.C. の入れ方、拍の位置の直し方、シンコペーション（食う）の付け方、コードの消し方、文字でまとめて打つ方法、ジャズ式と標準表記の切り替え

  • コードを1つ入れたい
  • 続けて、次の小節にも入れたい
  • 紙にある「C7(♭9)」「C/E」のようなコードを入れたい
  • コードの拍の位置を直したい・シンコペーションを付けたい
  • コードを文字でまとめて打ちたい
  • コードの書き方（ジャズ式と標準表記）を変えたい

コードを1つ入れたい

このアプリで作った曲で、小節があるとき

  1. 入れたい小節を押す。下（横向きでは右）にコード入力画面が開き、「コード」タブが出る
  2. 「この小節の拍」の並びで、コードを入れる拍のボタンを押す（例：「1拍目」）
  3. 「音名」で音を選ぶ。C を入れるなら「C」を押す
  4. 「種類」で種類を選ぶ。ただの C なら、「（なし）」（下に「メジャー」と書いてあるボタン）を押す
  5. 「入れる」を押す。選んだ拍にコードが入る
  6. 譜面に戻るときは、右上の「完了」を押す
  • 「入れる」の後も、コード入力画面は開いたまま
  • 次の拍へは、自動では進まない。次の拍のボタンを押してから入れる
  • 空の拍を選ぶと、種類は「（なし）」から始まる。コードの入った拍を選ぶと、そのコードの種類が出る
  • コードが1つも無い曲では、1小節目に薄い字で「押してコードを入力」と出る
  • 1小節にコードが入りきらないときも、コードは省かずに全部出す。1段の小節数を決めてある曲では、その小節のコードを全部同じ大きさにそろえて、小さく出す
  • 同じ小節の中で、すぐ前のコードと同じ和音のままベース音だけが変わるときは、アプリが「C」「/B」のように、斜線とベース音だけを出す。入れるときは、ふつうに「C/B」を入れる
関係する項目
  • 続けて、次の小節にも入れたい
  • 紙にある「C7(♭9)」「C/E」のようなコードを入れたい
  • コードを文字でまとめて打ちたい
  • PDF の譜面に書き込みたい

続けて、次の小節にも入れたい

  1. コード入力画面のいちばん上に、いまの小節の番号（例：「3小節目」）が出ている
  2. 番号の右の chevron_right で次の小節へ、左の chevron_left で前の小節へ移る
  3. 最後の小節では、chevron_right の代わりに「追加して次へ」が出る。押すと、空の小節が1つ増えて、そこへ移る
  4. 一度使ったコードは、「この曲で使ったコード（多い順）」に並ぶ。押すだけで、選んでいる拍に入る
  5. 入れ終えたら「完了」を押す
  • 選び途中のコードは、小節を移るときや「完了」を押したときにも入る
  • コード入力画面の上には「コード」「記号」「歌詞」のタブがある。小節を移っても、同じタブのまま開く

紙にある「C7(♭9)」「C/E」のようなコードを入れたい

  1. 「音名」で音を選ぶ。C♯ のような音は、「C」を押してから「♯」を押す
  2. 「種類」の上の分類（「メジャー系」「マイナー系」「ドミナント系」「その他」）で、探す種類の分類にチェックを入れる。チェックを入れた分類の種類だけが並ぶ。分類はいくつでも選べる
  3. 種類のボタンを押す。ボタンには、紙と同じ記号が大きく、名前が小さく出る（例：「m7」の下に「マイナー7th」）
  4. 括弧の中の数字（♭9 など）は、「付加テンション（任意）」で押す。もう一度押すと外れる
  5. 分数コード（オンコード）の「C/E」の「E」のような、斜線の後ろの音は、「ベース音を追加」を押してから、「ベース音」の並びで選ぶ
  6. 「入れる」を押す
  • 例：C7(♭9) は、「C」→「7」→「♭9」→「入れる」
  • 例：C/E（C onE）は、「C」→「（なし）」→「ベース音を追加」→「E」→「入れる」
  • 「ドミナント系」には、C7・C9・C13 のような、いわゆるセブンスの仲間が入っている
  • 「ベース音を追加」を押すと、音名の並びがベース音を選ぶ並びに替わる。種類を選び直すときは「コードに戻る」を押す。選んだベース音は残る
  • コードの無い所（N.C.）は、「N.C.」のボタン（下に「コードなし」）を押してから「入れる」を押す
  • 種類のボタンの記号は、曲の「コードの書き方」で変わる。ジャズ式なら Cm7 は「-7」と出る
  • チェックを入れた分類は、次に開いたときも残る
  • ボタンに無い書き方は、「まとめて直す」で文字のまま打てる
関係する項目
  • コードを文字でまとめて打ちたい
  • コードの書き方（ジャズ式と標準表記）を変えたい

コードの拍の位置を直したい・シンコペーションを付けたい

  1. 小節を押し、「この小節の拍」の並びで、直したいコードのある拍のボタンを押す
  2. 「← 前へずらす」か「後ろへずらす →」を押す。コードが、隣の空いた拍へ動く
  3. 書いた拍より8分音符ぶん早く弾く（食う）コードには、「シンコペーション」を押す
  4. 譜面のコードの左上に、タイの付いた小さな8分音符が付く。もう一度押すと外れる
  5. コードを消すときは「このコードを削除」を押す。小節のコードを全部消すときは「小節を空にする」（コードが2つ以上あるときに出る）
  • ずらすときは、コードの入った拍を飛び越す。ほかのコードは動かない
  • 小節の外へは動かせない。小節をまたいで動かすときは、「まとめて直す」で打ち直す
  • 「シンコペーション」は、「この小節の拍」の並びの右端にある。画面を分けて幅が狭いときは「食う」と出る
  • 「シンコペーション」は、コードのある拍を選んでいるときだけ出る
  • どの操作も、コード入力画面の上の undo（「取り消す」）で1回ずつ戻せる
関係する項目
  • コードを文字でまとめて打ちたい
  • 間違えた操作を戻したい

コードを文字でまとめて打ちたい

  1. 譜面の上のツールバーの「まとめて直す」を押す。「歌詞とコードをまとめて直す」の画面が開く
  2. 小節ごとの「コード」の欄に、コードを空白で区切って打つ（例：C . G .）
  3. 「.」は、前のコードが続くことを表す。コードと「.」を合わせた数で、小節を等分する。4/4 で4つ打てば、1つが4分音符ぶんになる
  4. 改行キーで、次の欄へ進む
  5. 打ち終えたら、キーボードの上の「完了」を押す。譜面に戻るときは、左上の arrow_back_ios_new を押す
  • Cm7 と C-7 のように、どちらの書き方でも入る
  • 繰り返しの |: :|、前の小節と同じの % も、同じ欄に打てる
  • 食うコードは、コードの前に ^ を打つ（例：^F）。キーボードの上に並ぶボタンの「^ シンコペーション」でも入る
  • A7(♭9,♭13) のように、括弧の中の , はテンションの区切りとして読む。括弧の中の空白も、コードの区切りにしない
  • キーボードの上に並ぶコードや記号のボタンを押すと、カーソルの位置に入る
  • コードとして読めない字は「.」に置き換え、「読めないので「.」にしました：（字）」と知らせる
関係する項目
  • 歌詞の切れ目が1小節ずれているのを直したい

コードの書き方（ジャズ式と標準表記）を変えたい

  1. 譜面の画面のいちばん上の曲名を押して、「曲の設定」を開く
  2. 「コードの書き方」で「ジャズ式」か「標準表記」を押す
  3. 「完了」を押す
  • ジャズ式は C-7・CΔ7、標準表記は Cm7・Cmaj7 のように出る
  • 曲ごとに選ぶ。入れてあるコードは変わらず、画面と PDF での書き方だけが変わる
