使い方

本番で演奏したい

演奏用の画面の開き方とページのめくり方、譜めくりペダル、演奏メニューの出し方、表示の切り替え（コード＋歌詞・歌詞カード・歌本スタイル）、D.S. や to Coda で飛ぶ方法、拡大、メトロノーム、チューナー、PDF の譜面への書き込み

  • 演奏用の画面で、ページをめくりたい
  • 演奏メニューを出したい・表示を変えたい
  • D.S. や to Coda から、飛び先のページへ移りたい
  • 譜面を大きく見たい
  • メトロノームを鳴らしたい
  • チューナーで音を合わせたい
  • PDF の譜面に書き込みたい

演奏用の画面で、ページをめくりたい

  1. 譜面の画面の右上の「演奏」を押す。細い窓では、再生の三角の印になる
  2. 画面の右の端（約3cm）を押すと次のページ、左の端を押すと前のページへめくる
  3. 指で横に払っても、めくれる
  4. 譜めくりペダルでもめくれる
  • ペダルは、キーボードの ↓ → Page Down で次、↑ ← Page Up で前に進むものが使える
  • スペースと Enter を送るペダルには対応していない
  • 演奏用の画面を開いている間は、画面が暗くならない
  • 初めて開いたときは、めくり方を吹き出しで教える
関係する項目
  • 演奏メニューを出したい・表示を変えたい

演奏メニューを出したい・表示を変えたい

  1. 左右の端（約3cm）より内側を押すと、上に演奏メニューが出る。初めて開いたときは、押す所を緑の枠で示す。左上の、半分透けた小さな丸を押しても出る
  2. 「表示の切り替え」で、「コード＋歌詞」「コードのみ」「歌詞カード」「歌本スタイル」から選ぶ
  3. 同じ所で、「曲名と作詞・作曲を含める」「メモを含める」を切り替えられる
  4. 暗い部屋では、「表示の切り替え」の「暗い表示」を押す。地が暗く、字が明るくなる 1.5.0 から
  5. 横向きの見開きのめくり方は、「めくり方」で「2枚ずつ」か「1枚ずつ」を選ぶ
  6. 演奏メニューを隠すときは、メニューの左の端の上向きの矢印を押す
  7. 演奏用の画面を閉じるときは、演奏メニューの右の端の「閉じる」を押す
  • 左上の丸を押しても、画面は閉じない。閉じるのは「閉じる」だけ
  • 「表示の切り替え」は、このアプリで作った曲だけにある。PDF の譜面には無い
  • 選んだ表示は、次に開いたときも同じになる
  • 「暗い表示」は、PDF の譜面でも使える。選んだものは、次に開いたときも同じになる 1.5.0 から
  • 暗い表示では、記号の色と蛍光ペンも、暗い地で見える色で出る。保存してある色は変わらない 1.5.0 から
  • 細い窓では、入りきらないボタンは演奏メニューの「…」の中にまとまる。メトロノームとチューナーは、アイコンにして演奏メニューに残す。アイコンを長押しすると、名前が出る 1.5.0 から

D.S. や to Coda から、飛び先のページへ移りたい

  1. 演奏用の画面で、譜面の D.S. や to Coda を押す
  2. 飛び先のページが開き、飛び先の記号が2秒ほど光る
  • D.S. はセーニョへ、to Coda はコーダへ、D.C. は1ページ目へ飛ぶ
  • 繰り返しの終わり（:‖）を押すと、繰り返しの始まりのページへ飛ぶ
  • 1番カッコを押すと、2番カッコのページへ飛ぶ
  • このアプリで作った曲だけ。PDF の譜面では飛べない
  • セットリストでは、同じ曲の中だけで飛ぶ

譜面を大きく見たい

  1. 演奏メニューの「拡大」を押す
  2. 出てきたつまみを動かし、100% から 200% の間で合わせる
  3. 元に戻すときは「100%に戻す」を押す
  4. このアプリで作った曲は、「余白を消す」を押すと、紙の上下の余白が消え、譜面が画面いっぱいに大きくなる 1.5.0 から
  • 拡大の倍率は、曲や PDF の譜面ごとに保存される。次に開いたときも同じ倍率で出る
  • 2本の指で広げると、その場だけ大きくなる。めくると「拡大」の倍率に戻る
  • 2本の指で広げている間は、1本の指で引くと見る所が動く
  • 大きくすると、紙の外の空いた所まで広がって見える 1.5.0 から

メトロノームを鳴らしたい

  1. 演奏メニューの「メトロノーム」を押す。メニューの下に、メトロノームの列が出る
  2. 再生の三角の印のボタン（「鳴らす」）を押す。四角の印に替わり、押すと止まる
  3. テンポは、マイナスの印（−）とプラスの印（＋）で1ずつ変える。押し続けると、続けて変わる
  4. テンポの数字を押すと、数字で打てる。決めたら「決める」を押す
  5. 「タップ」を拍に合わせて続けて押しても、テンポを決められる
  6. 音を出さずに見るだけにするときは、スピーカーの印（「音を消す」）を押す
  • 拍は、振れるメーターと、画面の縁の光でも分かる
  • 鳴らすかテンポを変えると、そのテンポが曲に書かれる
  • PDF の譜面では、「拍子」で拍子も選べる
  • 演奏メニューを隠しても、小さなメトロノーム（小窓）が譜面の上に残る
  • 小窓は、指で引いて好きな所に置ける。画面の左右の端に寄せると、縦に並ぶ
  • 小窓の形は、メトロノームの列の「小窓」で「ボタン」か「メーター」を選ぶ
  • 小窓の細い山形の印（「畳む」）を押すと、点滅する印だけに小さくなる
  • 止めているときは、小窓の「畳む」の所が「×」（「閉じる」）になる。押すと小窓が消える 1.5.0 から
  • 演奏用の画面を閉じると止まる。セットリストで曲が替わったときも止まる

チューナーで音を合わせたい

  1. 演奏メニューの「チューナー」を押す
  2. 初めてのときは、マイクの使用を許可する
  3. 楽器を鳴らす。音名と針が出る。針が真ん中で緑になれば合っている
  4. 基準の高さ（440Hz など）は、両側のボタンで変える。マイナスの印が「基準を下げる」、プラスの印が「基準を上げる」
  5. 耳で合わせるときは、音名の札（「鳴らす音」）で音を選ぶ
  6. スピーカーの印（「基準の音を鳴らす」）を押す。もう一度押すと止まる
  • チューナーを開くと、メトロノームは止まる
  • 「マイクを使えません。」と出たら、横の「設定を開く」を押し、Tofu のマイクを許可する 1.5.0 から
  • アンプにつながないエレキベースなど、音が小さい楽器は拾えないことがある

PDF の譜面に書き込みたい

PDF の譜面。このアプリで作った曲は「譜面に手書きでメモしたい」を見る

  1. 一覧で PDF の譜面を押す。演奏用の画面が開く
  2. 左右の端（約3cm）より内側を押して演奏メニューを出し、「書き込む」を押す
  3. ペンを選んで書く。消すときは「消しゴム」でなぞる
  4. 書き終えたら「完了」を押す
  • 書き込みの最中は、画面を押してもめくれない。ペダルではめくれる
  • ペンは、曲の手書きと同じものが使われる
  • 書き込みも、取り消し・やり直しができる
  • セットリストの演奏中は書き込めない。その PDF の譜面を開いて書き込む
前のページ紙の楽譜を取り込みたい次のページセットリストで本番に備えたい
Tofu 灯譜 は、コードと歌詞だけの譜面を作る iPad の無料アプリです。手元の楽譜を書き写して移調し、PDF の譜面と一緒にセットリストで演奏できます。広告なし・登録なし。
