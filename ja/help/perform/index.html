使い方

本番で演奏したい

演奏用の画面の開き方とページのめくり方、譜めくりペダル、演奏メニューの出し方、表示の切り替え（コード＋歌詞・歌詞カード・歌本スタイル）、D.S. や to Coda で飛ぶ方法、拡大、メトロノーム、チューナー、PDF の譜面への書き込み

  • 演奏用の画面で、ページをめくりたい
  • 演奏メニューを出したい・表示を変えたい
  • D.S. や to Coda から、飛び先のページへ移りたい
  • 譜面を大きく見たい
  • メトロノームを鳴らしたい
  • チューナーで音を合わせたい
  • PDF の譜面に書き込みたい

演奏用の画面で、ページをめくりたい

  1. 譜面の画面の右上の「演奏」を押す。画面を分けて幅が狭いときは、play_arrow のボタンになる
  2. 画面の右の端（約3cm）を押すと次のページ、左の端を押すと前のページへめくる
  3. 指で横にスワイプしても、めくれる
  4. 譜めくりペダルでもめくれる
  • 次のページへ進むキー：下矢印・右矢印・Page Down
  • 前のページへ戻るキー：上矢印・左矢印・Page Up
  • ペダルは、上のどれかのキーを送るものが使える。スペースや Enter を送るペダルでは、めくれない。ペダルによっては送るキーを切り替えられるので、ペダルの説明書を見る
  • 演奏用の画面を開いている間は、画面が暗くならない
  • 初めて開いたときは、めくり方を吹き出しで教える
関係する項目
  • 演奏メニューを出したい・表示を変えたい

演奏メニューを出したい・表示を変えたい

  1. 画面の真ん中あたりを押すと、上に演奏メニューが出る（左右の端の約3cmはページをめくる所）。初めて開いたときは、押す所を緑の枠で示す。左上の、半分透けた小さな丸を押しても出る
  2. 表示の切り替えのアイコン（tune）を押し、「コード＋歌詞」「コードのみ」「歌詞カード」「歌本スタイル」から選ぶ
  3. 同じ表示の切り替えの中で、「曲名と作詞・作曲を含める」「メモを含める」を切り替えられる
  4. 暗い部屋では、表示の切り替えの中の「暗い表示」を押す。背景が暗く、字が明るくなる
  5. 横向きで2ページ並べているときのめくり方は、演奏メニューの「めくり方」で選ぶ。「2枚ずつ」は、2ページがまとめて次の2ページに替わる。「1枚ずつ」は、1ページずつ進む
  6. 演奏メニューを隠すときは、メニューの左の端の keyboard_arrow_up を押す
  7. 演奏用の画面を閉じるときは、演奏メニューの右の端の「閉じる」を押す
  • 左上の丸を押しても、画面は閉じない。閉じるのは「閉じる」だけ
  • PDF の譜面の表示の切り替えには、「暗い表示」だけが出る
  • 選んだ表示は、次に開いたときも同じになる。「暗い表示」は、作った曲と PDF の譜面で共通
  • 暗い表示では、記号の色や蛍光ペンで書いた所も、暗い背景で見える色に変わる。明るい表示に戻せば、元の色に戻る
  • 画面を分けて幅が狭いときは、入りきらないボタンは演奏メニューの more_horiz の中にまとまる。メトロノームとチューナーは、アイコンにして演奏メニューに残す。アイコンを長押しすると、名前が出る

D.S. や to Coda から、飛び先のページへ移りたい

  1. 演奏用の画面で、譜面の D.S. や to Coda を押す
  2. 飛び先のページが開き、飛び先の記号が2秒ほど光る
  • D.S. はセーニョへ、to Coda はコーダへ、D.C. は1ページ目へ飛ぶ
  • 繰り返しの終わり（:‖）を押すと、繰り返しの始まりのページへ飛ぶ
  • 1番カッコを押すと、2番カッコのページへ飛ぶ
  • このアプリで作った曲だけ。PDF の譜面では飛べない
  • セットリストでは、同じ曲の中だけで飛ぶ

譜面を大きく見たい

  1. 演奏メニューの「拡大」を押す
  2. 出てきたスライダーを動かし、100% から 200% の間で合わせる
  3. 元に戻すときは「100%に戻す」を押す
  4. このアプリで作った曲は、「余白を消す」を押すと、ページの上下の余白が消え、譜面が画面いっぱいに大きくなる
  • 拡大の倍率は、曲や PDF の譜面ごとに保存される。次に開いたときも同じ倍率で出る
  • 2本の指で広げると、その場だけ大きくなる。めくると「拡大」の倍率に戻る
  • 2本の指で広げている間は、1本の指でドラッグすると見る所が動く
  • 大きくすると、譜面はページの枠で切れず、周りの空いた所まで広がって見える

メトロノームを鳴らしたい

  1. 演奏メニューの「メトロノーム」を押す。メニューの下に、メトロノームのボタンが並ぶ
  2. play_arrow（「鳴らす」）を押す。stop に替わり、押すと止まる
  3. テンポは、remove と add で1ずつ変える。押し続けると、続けて変わる
  4. テンポの数字を押すと、数字を入力できる。決めたら「決める」を押す
  5. テンポの数字を押して出る画面で、「タップ」を拍に合わせて続けて押しても、テンポを決められる。決めたら「決める」を押す
  6. 音を出さずに見るだけにするときは、volume_up（「音を消す」）を押す
  • 拍は、振り子のように振れるメーターと、画面の縁の光でも分かる
  • 鳴らすかテンポを変えると、そのテンポが曲に保存される。次に開いたときも、そのテンポになる
  • PDF の譜面では、「拍子」で拍子も選べる
  • 演奏メニューを隠しても、小さなメトロノーム（小窓）が譜面の上に残る
  • 小窓は、ドラッグして好きな所に置ける。画面の左右の端に寄せると、小窓が縦長になり、ボタンが縦に並ぶ
  • 小窓の形は、メトロノームの「小窓」で「ボタン」か「メーター」を選ぶ。「ボタン」は、点滅する印・remove・テンポの数・add・play_arrow が並ぶ。「メーター」は、点滅する印の代わりに、振り子のように振れるメーターが入る
  • 小窓の remove と add の間に、いまのテンポの数が出る。数を押すと、数字を入力できる 1.6.0 から
  • 小窓の chevron_left（「畳む」）を押すと、点滅する印とテンポの数だけに小さくなる
  • 止めているときは、小窓の「畳む」の所が close（「閉じる」）になる。押すと小窓が消える
  • 演奏用の画面を閉じると止まる。セットリストで曲が替わったときも止まる

チューナーで音を合わせたい

  1. 演奏メニューの「チューナー」を押す
  2. 初めてのときは、マイクの使用を許可する
  3. 楽器を鳴らす。音名と針が出る。針が真ん中で緑になれば合っている
  4. 基準ピッチ（A=440Hz など）は、数字の左右の remove（「基準を下げる」）と add（「基準を上げる」）で変える
  5. 耳で合わせるときは、「鳴らす音」で音を選ぶ
  6. volume_up（「基準の音を鳴らす」）を押す。もう一度押すと止まる
  • チューナーを開くと、メトロノームは止まる
  • 「マイクを使えません。…」と出たら、横の「設定を開く」を押し、Tofu のマイクを許可する
  • アンプにつながないエレキベースなど、音が小さい楽器は拾えないことがある

PDF の譜面に書き込みたい

PDF の譜面。このアプリで作った曲は「譜面に手書きでメモしたい」を見る

  1. 一覧で PDF の譜面を押す。演奏用の画面が開く
  2. 画面の真ん中あたりを押して（左右の端の約3cmはページをめくる所）演奏メニューを出し、「書き込む」を押す
  3. ペンを選んで書く。消すときは「消しゴム」でなぞる
  4. 書き終えたら「完了」を押す
  • 書き込みの最中は、画面を押してもめくれない。ペダルではめくれる
  • ペンの種類・色・太さは、作った曲に手書きするときと共通
  • 書き込みも、取り消し・やり直しができる
  • セットリストの演奏中は書き込めない。その PDF の譜面を開いて書き込む
前のページ紙の楽譜を取り込みたい次のページセットリストで本番に備えたい
Tofu 灯譜 は、コードと歌詞だけの譜面を作る iPad の無料アプリです。手元の楽譜を書き写して移調し、PDF の譜面と一緒にセットリストで演奏できます。広告なし・登録なし。
